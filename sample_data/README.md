# Original sample library

Five small, two-page PDFs accompany this project:

- Machine Learning Introduction
- Python Programming Guide
- Natural Language Processing Notes
- Data Mining Overview
- Web Development Fundamentals

All educational prose in `content.json` was written specifically for this project. No books, published papers or copyrighted articles were downloaded. The samples illustrate extraction and text statistics; they are not scholarly references.

Regenerate with `python tools/generate_samples.py`. Run `python seed.py` after migrating the database to create or restore their demo-user records. Seeding computes real text statistics and preserves existing accounts, passwords, and already-present sample records.
